# Insight log

This **public** skill does not include a named-project diary. Durable modeling and API rules live in [model.md](model.md), [gotchas.md](gotchas.md), [recipes.md](recipes.md), [auth.md](auth.md), [completeness.md](completeness.md), and [pbc.md](pbc.md).

Private Bluestone copies may keep a gitignored `insights.internal.md` (date, anonymous source, one line). Do not put customer names, plugin ids, SKU schemes, or engagement URLs in this public file.

When you learn a fact that will help the next catalog:

1. Write it in **generic** language (FAMILY / GROUP / VARIANT, CLA, VLA, relation vs attribute).
2. Put it in the playbook file above — not here.
